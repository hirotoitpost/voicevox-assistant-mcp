# セキュリティ

[English](../SECURITY.md) | 日本語

## 監査の概要

**2026-11-20** に `src/voicevox_assistant/` のすべてのコードを内部で確認しました。

**結果: セキュリティ上の問題は見つかりませんでした。** ローカルのハブについての注意点を下に書きます。

---

## 通信

通信はすべてこの PC の中で完結します:

| 相手 | 用途 |
|---|---|
| `http://127.0.0.1:50021` | VOICEVOX エンジン(`/version`、`/speakers`、`/audio_query`、`/synthesis`) |
| `http://127.0.0.1:38121` | アシスタント自身のハブ(MCP サーバー・フック → ハブ) |

外部のサービスには何も送りません。エンジンの場所は `VOICEVOX_URL`、ハブのポートは `VOICE_ASSISTANT_PORT` で変えられます。

### 構成

```
Claude Code ─(stdio)─ MCP サーバー ─┐
フック ─────────────────────────────┴─ HTTP 127.0.0.1:38121 ─ ハブ ─ HTTP 127.0.0.1:50021 ─ VOICEVOX
```

---

## ローカルのハブ

- ハブは **127.0.0.1 だけ**で待ち受けます。ほかの PC からはつながりません。
- **認証はありません。** 同じ PC のプロセスなら、文を読ませる・声を変える・静かにモードを切り替えることができます。
  ファイルを読む・コマンドを動かすことはできず、返すのは状態だけです。
- 要求は JSON で、知らない action は断ります。文は 1 文 300 字までに切ります。
- `VOICEVOX_URL` をほかの PC に向けると、要約が暗号化されない HTTP でそこへ送られます。

---

## フック

- フックは、Claude Code が標準入力で渡すイベントの JSON(イベント名・ツール名・入力)を読みます。
- 使うのはイベント名・ツール名と、シェルのときはコマンドがテスト・git らしいかだけで、それで**定型文を選びます**。
  ツールの入力・プロンプト・ファイルの中身は**どこにも送りません**。ハブに送るのは選んだ定型文だけです。
- 何も出力しない(Claude の文脈に文を入れない)ので、必ず 0 で終わります。

---

## データの扱い

- 読み上げる要約は Claude が書き、メモリーにだけ置きます。ログには残しません。
- 作った音声はメモリーに覚えておき(直近 64 文)、一時フォルダーの 2 つの wav ファイルに書いて再生します
  (文ごとに上書き)。
- 資格情報は使わず、保存もしません。

## コードの確認

次の危険なパターンを `src/voicevox_assistant/` で探し、**見つかりませんでした**:

- 動的なコード実行: `eval()`、`exec()`、`compile()`、`__import__()`
- シェルの呼び出し: `subprocess`、`os.system()`、`popen()`
- 難読化されたコードや怪しい import
